# 📧 增强版邮件管理器 - 设计说明

## 概述

这是对经典邮件管理器页面的全面优化升级，主要关注以下几个方面：

1. **可拖拽调整布局** - 支持拖拽分隔线调整面板宽度
2. **邮箱账户搜索** - 快速定位想要使用的邮箱账户
3. **响应式自适应布局** - 不同屏幕尺寸自动适配
4. **更好的视觉效果** - 现代化设计、流畅动画
5. **布局预设** - 支持保存和恢复布局配置

---

## 🎯 核心功能

### 1. 可拖拽调整面板宽度

**文件**: `resizable-panel.tsx`

- 侧边栏和邮件列表面板都可以通过拖拽分隔线调整宽度
- 拖拽时有视觉反馈（蓝色高亮）
- 拖拽手柄在悬停时显示
- 支持最小/最大宽度限制

**使用方式**:
- 将鼠标移到面板边缘，出现垂直拖拽手柄
- 按住鼠标左键拖拽即可调整宽度
- 侧边栏拖拽到最小宽度时会自动折叠

### 2. 邮箱账户搜索与过滤

**文件**: `enhanced-mailbox-sidebar.tsx`

**搜索功能**:
- 点击搜索图标打开搜索面板
- 支持按邮箱地址和服务商名称搜索
- 实时过滤，边输入边筛选
- 一键清除搜索条件

**过滤功能**:
- 按验证状态过滤（全部/已验证/未验证）
- 排序选项（按名称/按服务商）
- 升序/降序切换

**快捷统计**:
- 底部显示账户总数
- 显示已验证和未验证的数量

### 3. 响应式自适应布局

**文件**: `enhanced-classic-mailbox-view.tsx`

**桌面端** (>= 1024px):
- 三栏布局：侧边栏 + 邮件列表 + 邮件预览
- 支持拖拽调整各面板宽度

**平板端** (768px - 1024px):
- 自动缩小侧边栏宽度
- 保持三栏布局

**移动端** (< 768px):
- 单面板切换模式
- 底部导航切换面板
- 返回按钮导航

### 4. 布局预设管理

**内置预设**:
- **标准**: 侧边栏 280px, 邮件列表 400px
- **紧凑**: 侧边栏 200px, 邮件列表 320px
- **宽敞**: 侧边栏 320px, 邮件列表 500px
- **专注阅读**: 侧边栏折叠, 邮件列表 350px

**自定义预设**:
- 保存当前布局为自定义预设
- 自动保存布局配置到本地存储
- 重置为默认布局

**访问方式**:
- 点击邮件预览面板右上角的布局图标

## 🎨 样式增强

**文件**: `globals.css`

新增样式类:
- `.resizable-handle` - 拖拽手柄样式
- `.email-account-card` - 邮箱账户卡片样式
- `.search-input-enhanced` - 增强搜索框样式
- `.glass-card` - 玻璃态卡片效果
- `.mailbox-scrollbar` - 优化滚动条
- `.panel-shadow-left/right` - 面板阴影效果
- `.keyboard-shortcut` - 快捷键提示样式

新增动画:
- `layout-menu-enter` - 布局菜单进入动画
- `slide-in-left/right` - 移动端面板滑入动画
- `account-item-enter` - 账户列表项进入动画
- `status-pulse` - 状态指示器脉冲动画

## 💾 数据持久化

布局配置自动保存到 `localStorage`:
- 键名: `mailman-layout-config`
- 保存内容:
  - `sidebarWidth`: 侧边栏宽度
  - `emailListWidth`: 邮件列表宽度
  - `sidebarCollapsed`: 侧边栏折叠状态
  - `customPresets`: 自定义布局预设

---

## 🔄 兼容性

- 保留原有 `classic-mailbox-view.tsx` 不变
- 新组件独立，不影响现有功能
- 复用现有的邮件列表和预览组件
- 复用现有的邮件服务和账户服务
