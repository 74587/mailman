Token 存放

前端优先使用 localStorage.auth_token。

API Base

前端 service 默认请求 /api，开发环境可通过 NEXT_PUBLIC_API_URL 指定后端地址。

错误处理

401 会触发前端登出；403 表示权限不足；后端通常返回 message 或 error。

接口是否需要 Token说明
POST /api/auth/login否登录并获取 Bearer Token，登录入口有速率限制。
POST /api/auth/logout是退出当前会话。
GET /api/auth/me是获取当前用户、组织和权限上下文。
PUT /api/auth/update是更新当前用户资料。

请求与响应约定

请求头

Authorization: Bearer $TOKEN
Content-Type: application/json

上传、OAuth2 回调、WebSocket 握手等特殊接口除外；常规 JSON 写操作都使用上面两项。

分页

?page=1&limit=20
?limit=50&offset=0

账户列表常用 page/limit；邮件高级搜索常用 limit/offset。具体以专题页和 Swagger 为准。

HTTP 状态含义接入方处理
200 / 201读取、更新或创建成功。按接口响应结构处理。
204删除成功且无响应体。前端直接从列表移除。
400请求体或查询参数无效。展示后端文本错误并修正字段。
401未登录或 Token 失效。清理本地 Token，跳转登录。
403组织或权限校验失败。检查角色权限、资源所属组织或账户归属。
404资源不存在。确认 ID、组织上下文和是否已删除。
409唯一约束冲突。常见于标签组、代理组、模板名等重复。
500服务端或第三方依赖异常。收集请求 ID、资源 ID、后端日志时间段。
字段命名同时存在 snake_case 和 camelCase：后端 Go 模型决定 JSON 字段。例如同步使用 sync_interval，业务账户使用 emailAccountId，取件模板管理使用 outputConfig，取件内联模式使用 output_config。

WebSocket 与实时能力

等待邮件

GET /api/ws/wait-email

用于等待邮件到达。

订阅监控

GET /api/ws/subscriptions

用于订阅式邮件监控。

通知

GET /api/ws/notifications

用于前端通知推送。

如果 WebSocket 不适合当前运行环境，可使用 /api/poll-email 或 /api/pickup/poll 作为 HTTP 轮询方案。
